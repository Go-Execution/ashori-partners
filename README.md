# Ashori Partners LLC

Redesigned residential renovation and interior craftsmanship website for **Ashori Partners LLC** (Greater Boston, MA), replacing the legacy site at `ashoripartnersllc.com`.

## Core Disciplines
- **Kitchen Renovations** (`/services/kitchen`)
- **Bathroom Remodeling** (`/services/bathroom`)
- **Hardwood Flooring & Custom LED Staircases** (`/services/flooring`)
- **Interior Painting & Trimwork** (`/services/painting`)

## Tech Stack
- **Framework:** Next.js 16 (App Router, Static / SSG)
- **UI & Styling:** React 19, TypeScript, Tailwind CSS v4
- **Motion & Icons:** Motion (`motion/react` with `useReducedMotion`), Phosphor Icons (`@phosphor-icons/react`)

## Local Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```
